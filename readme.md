# Поиск пар

https://nikolai-khramkov.github.io/memory-game/

Игра на память: на поле 16 карточек, восемь рисунков встречаются по два раза. Нужно открывать карточки по две и найти все пары за наименьшее число ходов.

В шапке показаны число ходов и найденных пар, а также кнопки «Новая игра» и «Таблица лидеров». Совпавшая пара остаётся открытой. Несовпавшая пара видна около секунды и затем закрывается; пока она открыта, другие карточки выбрать нельзя. После восьмой пары открывается окно победы с итогом ходов. Десять лучших результатов хранятся в браузере и остаются после перезагрузки.

## Запуск

Нужны Node.js и npm. Из корня проекта:

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173).

Сборка статики: `npm run build`. Готовые файлы попадут в `dist`, их можно посмотреть через `npm run preview`.

## Управление

- Нажмите закрытую карточку, затем вторую.
- «Новая игра» в шапке или в окне победы сразу перемешивает поле и обнуляет счётчики, без перезагрузки страницы.
- «Таблица лидеров» показывает до 10 результатов: место, ходы и дату. Меньше ходов — выше. При равенстве выше более ранняя игра.
- Окно закрывается кнопкой «Закрыть», щелчком по затемнённому фону или клавишей Escape. Текущая партия при этом не сбрасывается.

Рисунки на карточках — собственные SVG-иконки, отдельные файлы изображений не используются.
